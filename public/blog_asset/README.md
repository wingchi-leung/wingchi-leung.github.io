# 博客图床目录

把文章里要用的图片放在这个目录下即可。

## 在 Markdown 里怎么引用

- **标准写法**：`![描述](/blog_asset/文件名.png)`
- **Obsidian 写法**（也支持）：`![[文件名.png]]` 或 `![[Pasted image 20251030204024.png]]`

图片路径都会指向 `/blog_asset/`，部署到 GitHub Pages 时会自动加上项目子路径。

## 建议

- 文件名尽量用英文、数字，避免空格和中文，减少编码问题。
- 从 Obsidian 粘贴的图片可先保存到本目录，再在文章里用 `![[文件名.png]]` 引用。
